The rules this sheet follows
  • Panels: the fewest panels that keep each panel 19–22″ of window. Only if no number of panels lands in 19–22″, up to 24″. The same on 140 cm and 300 cm rolls.
  • Each panel is the height + 6″ for the bottom fold + 4″ for the top heading. If the fabric has a pattern repeat, the length goes up to the next full repeat.
  • Metres = panels × length ÷ 39.37, rounded up to the next ¼ m.
  • A 300 cm roll, window under 109″ tall: used the normal way, 300 cm as the curtain's height. Metres = panels × 1.4 m.
  • A 300 cm roll, window 109″ or taller: turned, so 300 cm runs across the width. Each 300 cm width makes 2 panels, so panels come in pairs; metres = widths × length.
  • Lining: the same number of panels and the same length as the curtain (no pattern matching, never turned), rounded up to the next ¼ m.
  • Track = width ÷ 12, rounded up to the next ½ ft. Motor track = width in metres, rounded up to the next ½ m kit.
